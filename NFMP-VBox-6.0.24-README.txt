NFMP: развертывание в VirtualBox 6.0.24
========================================

Назначение
----------
Образ подготовлен для внутреннего сервера под управлением Windows Server 2012
и импорта в Oracle VM VirtualBox 6.0.24. Формат экспорта: OVF 1.0 (OVA).

Параметры ВМ
------------
- ОС: Ubuntu Server 24.04 LTS, 64-bit
- Процессоры: 4 vCPU
- Оперативная память: 6144 МБ
- Диск: 40 ГБ, динамический
- Сетевой адаптер: Intel PRO/1000 MT Desktop, сетевой мост
- Веб-интерфейс: http://10.97.101.209
- SSH: 10.97.101.209:22
- Опубликованные приложением порты: TCP 80 (HTTPS в закрытом сегменте не используется)

Требования к серверу
--------------------
- В BIOS/UEFI должна быть включена аппаратная виртуализация Intel VT-x или AMD-V.
- На диске сервера должно быть не менее 45 ГБ свободного места под ВМ.
- Для установки VirtualBox и импорта образа нужны права администратора Windows.
- Перед установкой проверьте, не используется ли роль Hyper-V. VirtualBox 6.0.24
  не следует запускать одновременно с гипервизором Hyper-V. Не отключайте роль,
  если на сервере работают другие Hyper-V ВМ: сначала согласуйте миграцию с
  администратором инфраструктуры.

Настройка сети
--------------
В гостевой ОС уже сохранены следующие параметры:

- IP-адрес: 10.97.101.209
- Маска: 255.255.255.0 (/24)
- Шлюз: 10.97.101.1
- DNS: 10.97.101.1, резервный 8.8.8.8

Если организация использует внутренний DNS, замените адреса DNS в
/etc/netplan/50-cloud-init.yaml на выданные администратором сети.

Перед первым запуском убедитесь, что адрес 10.97.101.209 свободен или
зарезервирован за этим сервером. Конфликт IP приведет к недоступности сайта.

Импорт и запуск
---------------
1. Откройте VirtualBox 6.0.24.
2. Выберите "Файл" -> "Импорт конфигураций" и укажите OVA-файл.
3. После импорта откройте "Настройки" -> "Сеть" -> "Адаптер 1".
4. Выберите тип подключения "Сетевой мост".
5. В поле "Имя" выберите физический сетевой адаптер сервера, подключенный
   к сети 10.97.101.0/24. Имя адаптера Windows не переносится внутри OVA.
6. Запустите ВМ и откройте http://10.97.101.209.

Если Windows Firewall блокирует подключения, разрешите входящие TCP-порты
80 (сайт) и 22 (SSH) для нужного сетевого профиля.

Учетные данные
--------------
Логины и временные пароли находятся в отдельном файле
NFMP-VM-CREDENTIALS.txt. Не загружайте этот файл в публичные хранилища и
смените оба пароля после первого запуска.

Обслуживание
------------
Каталог приложения: /opt/nfmp

Проверка контейнеров:
  cd /opt/nfmp
  docker compose -f docker-compose.prod.yml -f docker-compose.vm.yml ps

Перезапуск:
  cd /opt/nfmp
  docker compose -f docker-compose.prod.yml -f docker-compose.vm.yml up -d

Обновление после получения новой версии кода:
  cd /opt/nfmp
  git pull --ff-only
  docker compose -f docker-compose.prod.yml -f docker-compose.vm.yml up -d --build

Просмотр журналов:
  cd /opt/nfmp
  docker compose -f docker-compose.prod.yml -f docker-compose.vm.yml logs --tail=200

Резервные копии базы создаются каждые 24 часа, хранятся 7 дней, не более
7 копий. Каталог: /opt/nfmp/backups.

Карта
-----
Для загрузки подложки OpenStreetMap и поиска адресов нужен Интернет.
При отсутствии Интернета карту можно открыть с ранее закэшированной подложкой
и поставить точку вручную; координаты пожара сохраняются приложением.
Флаговый логотип Leaflet удален, обязательная ссылка на источник картографических
данных OpenStreetMap сохранена.

Ограничения
-----------
VirtualBox 6.0.24 и Windows Server 2012 больше не получают актуальные исправления
безопасности. Сервер следует держать во внутреннем защищенном сегменте, ограничить
доступ правилами межсетевого экрана и запланировать обновление платформы.

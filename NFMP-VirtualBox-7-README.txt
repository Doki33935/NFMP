NFMP: развёртывание в Oracle VM VirtualBox 7
================================================

Назначение
----------
OVA содержит Ubuntu Server 24.04 LTS, приложение NFMP и перенесённую рабочую
базу данных. Образ подготовлен и проверен в VirtualBox 7.2.

Параметры ВМ
------------
- ОС: Ubuntu Server 24.04 LTS, 64-bit
- Сеть гостевой ОС: статический адрес 10.97.101.209/24
- Шлюз: 10.97.101.1
- Сайт: http://10.97.101.209
- SSH: ssh -p 2222 nfmpadmin@10.97.101.209
- Каталог приложения: /opt/nfmp

Импорт и запуск
---------------
1. Откройте VirtualBox 7 и выберите "Файл" -> "Импорт конфигураций".
2. Укажите файл NFMP-Ubuntu-24.04-VirtualBox-7.ova.
3. После импорта откройте "Настройки" -> "Сеть" -> "Адаптер 1".
4. Выберите "Сетевой мост" и физический адаптер сервера, подключённый к сети
   10.97.101.0/24.
5. До запуска убедитесь, что адрес 10.97.101.209 свободен или зарезервирован
   за этой ВМ.
6. Запустите ВМ и откройте http://10.97.101.209.

Учётные данные
--------------
Учётные данные передаются отдельно и не хранятся в Git или внутри этой
инструкции. После первого запуска смените пароль ОС и пароль администратора
приложения.

Проверка
--------
  cd /opt/nfmp
  sudo docker compose -f docker-compose.prod.yml -f docker-compose.vm.yml ps
  sudo docker compose -f docker-compose.prod.yml -f docker-compose.vm.yml logs --tail=100 backend web db caddy

Проверить сайт из гостевой ОС:
  curl -I http://127.0.0.1

Обслуживание
------------
Перезапуск без пересборки образов:
  cd /opt/nfmp
  sudo docker compose -f docker-compose.prod.yml -f docker-compose.vm.yml up -d --no-build

Обновление при наличии Интернета:
  cd /opt/nfmp
  git pull --ff-only origin dev
  sudo docker compose -f docker-compose.prod.yml -f docker-compose.vm.yml up -d --build

Резервные копии создаются каждые 24 часа, хранятся 7 дней, не более 7 файлов.
Каталог: /opt/nfmp/backups.

Карта
-----
Основная подложка загружается из OpenStreetMap, при сбое автоматически
используется резервная подложка CARTO. Обе подложки требуют Интернет.
Локальные границы муниципальных образований, существующие метки и ручная
установка новой точки работают без Интернета.

Сеть и безопасность
-------------------
На межсетевом экране разрешите TCP 80 и TCP 2222 только для доверенной сети.
Порты PostgreSQL и backend наружу не публикуются. ВМ должна регулярно получать
обновления Ubuntu и Docker.

Не выполняйте docker compose down -v: параметр -v удаляет том PostgreSQL.
